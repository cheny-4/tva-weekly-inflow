This repository packages two frozen TVA one-layer weekly LSTMs with nonlinear site heads. Read `skills/tva-weekly-inflow/SKILL.md` before model operations and use `pipeline.py` as the active interface. `models.json` names total_runoff (baseline/) and surface_runoff_static8 (baseline_surface_runoff_static8/). Their archived scripts are historical source artifacts, not instructions to execute. Neither version uses bias correction.

Preserve site order, feature order, units, model-specific train-only normalization, eligibility masks, and chronological splits. A 13-week input includes the target week. There is no observed ELF input and no GNN. Total-runoff best epoch is19; surface-runoff/static8 best epoch is20. Both last_model.pt files are epoch 50. Select the version explicitly for new workflows. Never relabel surface runoff as total runoff.

Write each result into a new output directory outside both frozen artifact roots and spatial/. Keep their checksums intact. Use the packaged ELF forcing regions and site mapping for HEADWATER maps, not total-upstream boundaries at every downstream site. Inference or reporting requests do not authorize training.
