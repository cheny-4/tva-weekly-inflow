# Frozen model versions

models.json selects paths, exact feature order, runoff semantics, parameter count and best epoch. Total version lives in baseline/, source run weekly13_lstm1_nonlinear_cosine_s42_5751784. Surface version lives in baseline_surface_runoff_static8/, source run weekly13_lstm1_surface_static8_s42_5833188. Each export_manifest.json records source paths and SHA256. Both archived snapshots stay unchanged; no bias-correction artifacts are included.

Both models use one 64-unit LSTM, dropout0.2 before 52 independent nonlinear 64→16 ReLU→1 Softplus site heads, and 13 weeks including the target. Total has 4 LSTM inputs (P,T,total runoff,elevation) and 72,884 parameters. Surface has 12 LSTM inputs (P,T,surface runoff,9 statics) and 74,932 parameters. Site order is ELF01–ELF52. Head IDs cannot be reassigned to new sites. Neither model uses GNN, attention, CAMELS, observed ELF lags or historical median.

Dynamic order is precipitation_mm_week, temperature_mean_c, and the model's total_runoff_mm_week or surface_runoff_mm_week. Historical T was estimated from Daymet(Tmax+Tmin)/2. P/runoff are basin mean weekly depths, not sums of grid-cell depths. Surface excludes time-varying NLDAS Qsb. Statics are elevation alone, or elevation plus permeability, sand%, clay%, bedrock depth, water-table depth, BFI%, 2019 riparian impervious% and 2019 open-water%. Source-native permeability/depth units are retained. Static BFI comes from external StreamCat, not ELF test targets; impervious cover is a 100 m riparian descriptor. See the surface static_preparation/static_audit.json for coverage/provenance.

The NPZ holds 1816 weeks×52 sites×3 dynamic features, static shape 52×1 or52×9, float32 training targets, float64 reference targets, flags/masks and split. P,T,elevation, target/mask/split arrays are identical across versions; runoff/scalers and additional static columns differ as intended. Do not refit scalers on new forecasts or test data. Physical features enter as float32 before original training scaling returns float32.

Both runs: train1982–2004, validation2005–2009, test2010–October2016;50,084/9,868/15,025 valid rows, including11,155/2,297/3,375 at the ten headwaters. Keep eligible, target_valid_all7 and inherited graph_history13_valid despite the legacy name. Nickajack has no valid test targets. Finite or positive target values alone do not establish validity.

Loss is mean(((prediction−target)/(training site std+0.1))²). The site std scales loss only; the positive output is already physical mm/day. Volume equals output×target area_km2× 7000. Target areas are not additional learned statics and can differ from the polygons for shared forcing-source groups.

Adam0.001,batch512,clip1,seed42,cosine50 to0.00001,all50 epochs,no early stopping. Minimum ten-headwater validation loss selects total epoch 19 and surface epoch 20; last_model.pt is epoch 50. Original surface initialization preserved the original four input weights and initialized eight new input columns to zero, all trainable. The portable train interface keeps that module initialization.

Historical test median NSE: total 0.8209 all 51/0.8742 headwater 10; surface 0.7473 all 51/0.8034 headwater 10. Do not present these as percent accuracy or prospective forecast validation. Fixed 2019 descriptors in a 2010–2016 test are not strict as-of-date information. The repeatedly inspected test period remains exploratory.

Spatial support comes from spatial/forcing_regions.geojson and site_region_mapping.csv. These 43 regions preserve the original USGS reconstruction, local/incremental target and source/proxy qualifications. Some sites share a forcing-region average while retaining their own output heads and target areas. Inference coupling should preserve that support, not route/sum all outputs as cumulative upstream flow.
